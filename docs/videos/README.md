## 生成步骤

```bash
cd web
npm ci
npx playwright install chromium
npm run build
npm run record:guides
# 仅执行脚本自检，不启动服务、不写数据库：
node ../scripts/record-guides.mjs --self-test
```

## 录制与校验边界

- 脚本自动创建临时 SQLite 数据库和本机随机端口服务，调用现有迁移、账号初始化命令；不接收远程服务地址或现有账号口令。
- 使用随机密码与临时密钥，管理员 MFA 策略保持开启。二维码、TOTP 密钥、恢复码、客户端密钥在渲染前遮挡；密码输入框保持隐藏。
- 录制结束关闭浏览器和临时服务并清理临时数据库；不修改 `data/user-center.db` 或部署配置。
- 当前开发配置连接数为 1，初始化账号时存在事务内额外读取等待；录制专用配置使用 5 个连接，并沿用 HTTP 测试的文件数据库连接格式，不启用 shared-cache。不修改项目配置与业务代码。
- 每段完成关键页面或结果断言、检查浏览器未捕获异常；MFA 二维码、恢复码与客户端密钥在导出截图前检查遮挡，不依赖二维码像素尺寸。失败立即返回非零退出码，不输出响应正文或凭据；服务启动失败时提供有长度限制、已脱敏的诊断。成功后写入 `manifest.json`，记录本次录制时间与清单。
- 移动端仅检查个人资料、组织列表并断言没有整页横向溢出，**不等于全站移动端验收**。
- SCIM 凭据在导出前遮挡；目录源只填写表单不提交，录制过程不产生任何外部目录请求。
- 注册、找回密码、邮件激活、邮箱换绑、邀请接受、真实第三方登录及硬件 Passkey 不在本次录屏覆盖内；这些流程仍需 SMTP、上游供应商配置或真实设备验收。
- 视频、截图与目录页一并随仓库提交，克隆后即可离线查看。重新录制会覆盖对应媒体文件，提交前复核遮挡与操作结果。
